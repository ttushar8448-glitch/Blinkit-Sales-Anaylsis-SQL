Blinkit Business & Sales Analysis using SQL

Project Overview

This project focuses on analyzing Blinkit’s retail sales dataset using SQL. The objective is to explore sales performance, product categories, outlet characteristics, and business trends to generate meaningful insights.

Business Objectives

* Analyze total sales and average sales.
* Identify top-performing product categories.
* Compare sales across different outlet types.
* Analyze outlet establishment trends.
* Understand the impact of item characteristics on sales.
* Generate insights to support business decisions.

Tools & Technologies

* PostgreSQL
* pgAdmin 4
* SQL

SQL Concepts Used

* SELECT, WHERE, ORDER BY
* GROUP BY and HAVING
* Aggregate Functions (SUM, AVG, COUNT)
* CASE Statements
* JOINS
* Subqueries
* Common Table Expressions (CTEs)
* Window Functions (if used)

Key Analysis

1. Overall Sales Performance
2. Item Category Analysis
3. Outlet-wise Sales Analysis
4. Fat Content Analysis
5. Outlet Size and Location Analysis
6. Business Performance Trends

Key Insights

The analysis helps identify important sales patterns, understand product performance, compare outlet performance, and support data-driven business decisions.

Project Files

* blinkit_dataset.csv – Raw dataset
* blinkit_analysis.sql – SQL queries used for analysis
